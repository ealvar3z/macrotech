# v0.7.3 Windows test repair

The v0.7.2 Windows build correctly stopped because an automated test failed. The failing test substituted a PDF path without creating the file, then the real Windows branch attempted to open it. Linux did not exercise that branch, which is why the prior isolated run passed.

v0.7.3 creates an actual temporary PDF for the test and replaces the Windows file-opening call with an in-memory recorder. The test now verifies both the authoritative saved quotation payload and the Windows open request without launching a viewer during the build.

The test count remains 68. The React/TypeScript production build, isolated suite, and desktop self-test pass in the audit workspace. The real Windows build must still complete on a Windows computer before this package is considered Windows-verified.

No production service, Tracker, Gmail, OAuth, Firebase Hosting, or Cloud Run action was performed.
