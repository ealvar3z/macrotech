# Macrotech v0.8.0 — Employee Workflow Pilot

Read V0.8.0_RELEASE_REVIEW.md for installation, the 13 implemented tallies, test setup and remaining Windows/connected checks. That document supersedes historical audit notes.

This is source plus the compiled React dashboard and Windows builder, not a prebuilt signed installer. Extract the entire ZIP and run BUILD WINDOWS EXE.cmd. Only a successful Windows build produces READY_TO_TEST and the application EXE.

Settings → About must show 0.8.0-demo. The new version keeps data separate from prior pilots. Start with a reference example or new quotation. Test Save, optional notes, hidden discount requests, submission/approval, archive/restore and customer attachments.

Automatic Dummy synchronization requires the simulated CEO to enable controlled test destinations under Settings → My Tracker. Employees no longer trigger manual master writes. Without setup, submissions remain saved with pending sync status. The live 2026 Tracker is blocked from writes. Email sending remains disabled.

No production systems were modified. Windows execution and connected tests have not been certified; this is not a zero-bug guarantee.
